# FusionBridge MediaProjection — respaldo histórico

Este directorio conserva el prototipo anterior para una reversión mediante Git.
No participa en CMake, QRC, imports QML ni en las fuentes Java de Android.
InGe Earth usa exclusivamente `src/retroplasma` y `RetroplasmaEarthView.qml`.

Los scripts y pruebas históricos conservan sus rutas originales como referencia;
no son verificadores del motor actual. Cesium permanece en su respaldo existente.
