# Third-party notices — MapLibre map stack

InGe+ V38 integrates with MapLibre Native Qt when the dependency is prepared locally.

- MapLibre Native core: BSD 2-Clause.
- MapLibre Qt/QML bindings: terms described in the upstream `LICENSES` directory.
- Upstream examples used as architectural reference: MIT.
- Basemap style/tiles: OpenFreeMap using OpenStreetMap data.

The complete upstream license texts are copied by `00_PREPARAR_MAPLIBRE_ANDROID.ps1` into `thirdparty/maplibre-licenses/` and must remain available for release packaging and compliance review.
